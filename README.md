# Monitoreo Camiones SOLTRANS

Herramienta offline para gestionar placas, credenciales GPS y links de monitoreo.

## Link permanente

**https://davidrodriguezsilvarodriguez-commits.github.io/monitoreo-soltrans/**

O abre el archivo index.html directamente en el navegador.

## Caracteristicas
- Base de datos de placas y empresas
- Favoritos personales
- Carga masiva de placas
- Copiar usuario/contrasena
- Abrir monitoreo con 1 clic
- Exportar / Importar JSON
- 100% offline despues de la primera carga
